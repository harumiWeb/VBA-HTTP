# Getting started

## Requirements

VBA-HTTP targets Windows Excel running on a Windows x64, 64-bit Office installation. The
library uses late-bound WinHTTP for its default buffered client, so a WinHTTP
type-library reference is not required. The native client additionally uses
the Windows WinHTTP API through pointer-safe declarations.

32-bit Office is unsupported by policy. HTTP/3/QUIC is also unsupported; the
retained HTTP/3 enum is diagnostic-only and must not be used as a production
compatibility claim.

## Install the source package

The primary distribution is `VBA-HTTP-vX.Y.Z-source.zip` (or the unversioned
development package produced by `task release:source`). It contains the
production `.bas`/`.cls` modules, a manifest, hashes, installer, uninstaller,
and license notices.

1. Close the target workbook and keep a backup outside the workbook directory.
2. Extract the ZIP on Windows.
3. Run the installer from the extracted package:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass `
     -File .\Install-VBAHttp.ps1 `
     -Workbook C:\Work\Consumer.xlsm
   ```

4. Review the backup path printed by the installer before opening the workbook.
5. Add a reference to the workbook's `VBAHttp` module by using the factory
   functions; do not instantiate `PublicNotCreatable` classes from another
   workbook.

The installer validates the manifest and component hashes before importing,
imports only production components, and creates a recoverable backup. An
intentional upgrade uses `-Force`; retain the backup until the new workbook has
passed the consumer smoke test. To restore the previous state, close Excel and
use the backup generated by the installer, or run the package uninstaller:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File .\Uninstall-VBAHttp.ps1 `
  -Workbook C:\Work\Consumer.xlsm
```

The exact manifest, rollback, and path-safety rules are specified in
[`../specs/source-package.md`](../specs/source-package.md).

## First request

```vb
Option Explicit

Public Sub GetStatus()
    Dim client As HttpClient
    Dim response As HttpResponse

    Set client = VBAHttp.CreateClient()
    Set response = client.GetResponse("https://example.test/status/204")

    If response.IsSuccess Then
        Debug.Print response.StatusCode, response.ProtocolUsed
    Else
        response.RaiseForStatus
    End If
End Sub
```

For a reusable client, set `BaseUrl` once and pass relative paths. The client
resolves the URL, clones the request, applies defaults, and leaves the caller's
request object unchanged:

```vb
Dim client As HttpClient
Set client = VBAHttp.CreateClient()
client.BaseUrl = "https://api.example.test/v1"

Set response = client.GetResponse("users?page=1")
response.RaiseForStatus
```

`GetResponse`, `PostResponse`, `PutResponse`, `PatchResponse`, and
`DeleteResponse` are convenience methods. Use `CreateRequest` plus `Execute`
when method, headers, query, body, timeout, or transport options must be
configured explicitly.

## Choosing the backend

`VBAHttp.CreateClient()` selects the late-bound COM backend. It is the default
for buffered requests and has the broadest compatibility with ordinary
workbooks. `VBAHttp.CreateNativeClient()` selects synchronous native WinHTTP;
it is required for `DownloadFile`, `UploadFile`, `UploadMultipart`, and native
protocol/decompression controls.

```vb
Dim nativeClient As HttpClient
Set nativeClient = VBAHttp.CreateNativeClient()
Set response = nativeClient.GetResponse("https://api.example.test/ping")
```

The two backends share the public response and error model. A capability that
cannot be represented safely by COM is rejected before network I/O rather than
silently ignored. See [Transport capabilities](transport-capabilities.md).

## Handling failures

Use `RaiseForStatus` when a non-2xx status should follow normal VBA error
handling. For a result-oriented flow, inspect `StatusCode`, `IsSuccess`, and
the stable error category. Never parse a native WinHTTP error number directly;
use `HttpErrors.CategoryFromNumber` or the result object's error fields.

```vb
On Error GoTo Failed
Set response = client.GetResponse("https://api.example.test/data")
response.RaiseForStatus
Exit Sub

Failed:
    Debug.Print HttpErrors.CategoryName(HttpErrors.CategoryFromNumber(Err.Number))
    Debug.Print Err.Description
```
